# Organize the course around four Bootlin slide decks

Status: accepted

Supersedes: [0002-driver-curriculum-and-lab-boundaries.md](0002-driver-curriculum-and-lab-boundaries.md)

The learning path uses Bootlin's Embedded Linux, kernel driver, Yocto and debugging slide decks in that order. The local website indexes their sections, displays the original PDFs and records section completion in browser storage. The previous original curriculum and notes interface are retired; existing browser data is not migrated.

Keep the original PDF notices, credit Bootlin and identify the CC BY-SA 3.0 license. Record each source and snapshot. The slides are third-party teaching material, not a claim that this project has verified their labs. Identify electrical, storage and recovery risks before suggesting practical hardware actions.

# Use a local course and browser storage

Status: accepted; the notes interface is retired by [0003-four-slide-courses.md](0003-four-slide-courses.md).

The course runs locally without an account, database or cloud service. Course content is stored in the project; lesson progress and notes are stored in the current browser. This keeps the site simple and usable offline. Browser data does not automatically sync across browsers or computers and can be lost when it is cleared. External references and software downloads may require internet access.

Changes must preserve existing course data and browser storage unless the user explicitly requests a destructive operation. Introducing accounts, remote storage or synchronization changes this decision and requires a new decision.

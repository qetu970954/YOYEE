# Structure the driver curriculum around the BeagleBone

Status: superseded by [0003-four-slide-courses.md](0003-four-slide-courses.md)

Use the Bootlin kernel and driver course's topic and lab sequence as the reference for an original, self-contained English curriculum. The target is the BeagleBone Black Rev C, with native Ubuntu 24.04 as the primary development host. Retain embedded Linux foundations, system-building material and the LCD project as prerequisites or extensions. Check the license of any source material before reuse or adaptation.

Prefer labs that use the learner's existing equipment. Software alternatives can teach transferable mechanisms, but they are not equivalent to physical device validation. Record what was built, executed or verified on hardware, and identify remaining limitations. Protect the board, host and data by verifying electrical compatibility, device identity and recovery before hardware or destructive operations.
